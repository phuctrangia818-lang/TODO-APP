CLI TODO APP

A simple command-line Todo application built with Python.

Features
- Add task
- Delete task
- Show task
- Complete task
- Search task
- Search easy task
- Search medium task
- Search hard task
- Empty the list
- Exit the app

Project structure
todo_app/
| 
|- main.py -> main application flow
|- task.py -> task management logic
|- storage.py -> save/load JSON data
|- ultis.py -> helper functions

Installation
- Python 
- VS CODE/ Pycharm

Future improvements
- Add SQLite database
- Improve search system
- Add task due dates
